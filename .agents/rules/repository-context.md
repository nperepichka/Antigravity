# Repository Meta-Context: Antigravity Config Master

This workspace repository is the master source-of-truth for the user's **Google Antigravity global configuration** (Rules, Global Workflows, and Skills).

## Operational Context
- **Source of Truth:** Any changes to `GEMINI.md`, `config/global_workflows/*.md`, or `config/skills/**` in this repository represent core Antigravity meta-engineering that will be synchronized to the global configuration directory (`~/.gemini/config/`).
- **Tandem Architecture:** All workflows (`investigate`, `implement`, `review`, `debug`, `describe`, `checkpoint`) operate in strict synergy as a unified, cohesive engineering lifecycle.
- **Immediate Task Execution:** When the user initiates a session with a direct task or modification (e.g., editing rules, updating workflow logic, refining skills), treat it immediately as an Antigravity customization task without requiring the user to explain the repo's purpose, the tandem nature of the workflows, or the global deployment model.
